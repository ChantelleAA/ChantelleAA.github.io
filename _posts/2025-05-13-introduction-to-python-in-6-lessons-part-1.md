Python is a very popular programming language, for its widespread use and versatility.
It is also relatively easy to learn and use and it seems to be widely required for several roles such as 
data scientist, data analyst, machine learning engineer, etc.  

A number of people have seen the importance of the programming language but have hesitated to take the first step in learning
to programme in Python simply because of how duanting it appears.
I would like to try to fix that. This article is the beginning of a series of 6 articles which aim to introduct Python to 
a lay person who has some basic understanding of how a computer works.  

First things first, what is Python?

### What is Python?
Python is a [computer programming language](https://study.com/learn/lesson/programming-language-types-examples.html)
that was initiated in the late 1980s and specifically implemented in December 1989 by [Guido van Rossum](https://en.wikipedia.org/wiki/Guido_van_Rossum)
who was then working at CWI (Centrum Wiskunde & Informatica) in Amsterdam
